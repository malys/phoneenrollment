# Phone Enrollment

## Installation

```bash
# Tooling
npm run preinstall

# Synchronization
## Push
npm run push

## pull
npm run pull

# URLs
##  open dev URLs
npm run dev

## open production URLs
npm run prod
```


## Deploy

### Permalink for production

    Manage deployments: under "Active" at top left, make sure you have the right deployment selected.
    Then click on the pencil icon at the top right to edit this deployment. Click on the "Version" dropbox and "New version", then "Deploy". This will update this version with your newest code and keep the same URL as you are not making a new deployment.
